## The Relationship Between Recipe Ratings and the Time They Take
### **Introduction**
The dataset I am using is the Recipe and Ratings dataset which features 83,782 unique recipes and 731,927 user ratings. The recipes contain attributes such as the time it takes to complete them, the number of steps, ingredients, and nutritional value through factors like calories and protein. This data offers the opportunity to analyze and draw connections to ultimately answer the question of what makes a recipe "good" to users who try them.
